# CONCEITO
Selection Sort é um algoritmo de ordenação  dos mais simples. Pode ser implementado OUT OF PLACE (criando um novo vetor do tamanho da entrada) ou IN PLACE (no próprio vetor).

O Selection Sort OUT OF PLACE pode ser imaginado como ter um baralho de cartas desordenado na mão esquerda e a mão direita vazia. A medida que encontramos a menor carta na mão esquerda, passamos essa carta para a mão direita.

Esquematizando
- percorrer o vetor inteiro para achar o menor valor
- adicionar esse valor no primeira posição do vetor ordenado
- repetir esse processo para o segundo menor valor 
- ...

Dessa forma podemos observar cada iteração do algoritmo se comporta dessa maneira:


| Vetor Original      | Vetor Ordenado      |
| ------------------- | ------------------- |
| [7, 8, 3, 1, 6, 15] | [0, 0, 0, 0, 0, 0]  |
| [7, 8, 3, 6, 15]    | [1, 0, 0, 0, 0, 0]  |
| [7, 8, 6, 15]       | [1, 3, 0, 0, 0, 0]  |
| [7, 8, 15]          | [1, 3, 6, 0, 0, 0]  |
| [8, 15]             | [1, 3, 6, 7, 0, 0]  |
| [15]                | [1, 3, 6, 7, 8, 0]  |
| [ ]                 | [1, 3, 6, 7, 8, 15] |

Podemos também fazer a implementação IN PLACE do Selection Sort em que nós utilizamos o próprio vetor como suporte. Na primeira iteração trocamos de lugar o menor elemento com o primeiro elemento, o segundo menor na segunda posição e assim por diante.

Aqui está a implementação em go do Selection Sort IN PLACE

``` Go
func SelectionSort_IN(v []int) {

	for i := 0; i < len(v)-1; i++ {
		idx_menor := i
		for j := i + 1; j < len(v); j++ {
			if v[j] < v[idx_menor] {
				idx_menor = j
			}
		}
		v[i], v[idx_menor] = v[idx_menor], v[i]
	}
}
```

Ao fazer a análise assintótica desse algoritmo percebemos que ele tem uma complexidade muito ruim. Pois percorremos o vetor inteiro várias vezes, de forma que se o vetor tem tamanho N, obtemos a seguinte PA:

N + (N -1) + (N - 2) + ... (N - N + 1) = N(N - 1)/2   => O(N^2)

Complexidade de N^2, não é estável e não percebe quando está ordenado
