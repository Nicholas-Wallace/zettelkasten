# CONCEITO
O Merge Sort é um algoritmo de complexidade muito boa e relativamente simples de se implementar. Ele parte do seguinte princípio, que é a função merge:

Se temos dois vetores ordenados, podemos "mergea-los" criando um novo vetor ordenado da seguinte forma: A cada iteração o menor valor será copiado para o vetor mesclado:

| iteração | vetor esq     | vetor dir     | resultante                     |
| -------- | ------------- | ------------- | ------------------------------ |
| 1        | [3,3,4,6,9]   | [*1*,2,5,7,8] | [_, _, _, _, _, _, _, _, _, _] |
| 2        | [3,3,4,6,9]   | [1,*2*,5,7,8] | [1, _, _, _, _, _, _, _, _, _] |
| 3        | [*3*,3,4,6,9] | [1,2,5,7,8]   | [1, 2, _, _, _, _, _, _, _, _] |
| 4        | [3,*3*,4,6,9] | [1,2,5,7,8]   | [1, 2, 3, _, _, _, _, _, _, _] |
| 5        | [3,3,*4*,6,9] | [1,2,5,7,8]   | [1, 2, 3, 3, _, _, _, _, _, _] |
| 6        | [3,3,4,6,9]   | [1,2,*5*,7,8] | [1, 2, 3, 3, 4, _, _, _, _, _] |
| ...      | ...           | ...           | ...                            |

A sacada do merge sorte é que nós dividimos o vetor até termos um vetor de tamanho 1 (que nós temos certeza que está ordenado) depois disso aplicamos o merge com os vetores ordenado. Nós *dividimos* -> (literalmente dividir o vetor) para *conquistar* -> (reconstruir o vetor).


| vetor(es)                                        | operação  |
| ------------------------------------------------ | --------- |
| [9,4,3,6,3,2,5,7,1,8]                            | divisão   |
| [9,4,3,6,3], [2,5,7,1,8]                         | divisão   |
| [9,4], [3,6,3], [2,5,7,1,8]                      | divisão   |
| [9], [4], [3,6,3], [2,5,7,1,8]                   | conquista |
| <u>[4, 9]</u> , [3,6,3], [2,5,7,1,8]             | divisão   |
| <u>[4, 9]</u> , [3] , [6,3], [2,5,7,1,8]         | divisão   |
| <u>[4, 9]</u> , [3] , [6], [3], [2,5,7,1,8]      | conquista |
| <u>[4, 9]</u> , <u>[3, 6]</u> , [3], [2,5,7,1,8] | conquista |
| <u>[4, 9]</u> , <u>[3, 3, 6]</u>, [2,5,7,1,8]    | conquista |
| <u>[3, 3, 4, 6, 9]</u>, [2,5,7,1,8]              | divisão   |
| ...                                              | ...       |

Dessa forma já temos uma ideia de como implementar o Merge Sort, sempre resolvendo o lado da esquerda para depois resolver o lado da direita. É um algoritimo recursivo.

Primeiro vamos implementar a função merge. É importante passar como parâmetro para a função merge o novo vetor, dessa forma fica melhor de utilizar futuramente de forma recursiva o MergeSort completo.
``` Go 
func merge(new_vec []int, esq []int, dir []int) {

	// é preciso criar um index para iterar o esq e um para o dir
	iesq := 0
	idir := 0
	for iesq < len(esq) && idir < len(dir) {
		if esq[iesq] < dir[idir] {
			new_vec[iesq+idir] = esq[iesq]
			iesq++
		} else {
			new_vec[iesq+idir] = dir[idir]
			idir++
		}
	}
	for idir < len(dir) {
		new_vec[iesq+idir] = dir[idir]
		idir++
	}
	for iesq < len(esq) {
		new_vec[iesq+idir] = esq[iesq]
		iesq++
	}
}
```

de posse do merge agora podemos escrever o algoritmo recursivo para o MergeSort
``` Go
func MergeSort(v []int) {
	if len(v) != 1 {
		len_E := len(v) / 2
		len_D := len(v) - len_E

		fmt.Println(len_E)
		fmt.Println(len_D)

		v_E := make([]int, len_E)
		v_D := make([]int, len_D)

		for i := 0; i < len_E; i++ {
			v_E[i] = v[i]
		}
		for i := 0; i < len_D; i++ {
			v_D[i] = v[i+len_E]
		}

		fmt.Println(v_E)
		fmt.Println(v_D)

		MergeSort(v_E)
		MergeSort(v_D)
		merge(v, v_E, v_D)
		fmt.Println("merged:", v)
	}
}
```

Analisando a complexidade assintótica desse algoritmo é fácil ver quantas iterações são feitas, se pensarmos a etapa de divisão como uma BST de altura log(N) e em cada nível da árvore são feitas N operações. Dessa forma o algoritmo tem complexidade N*log(N).
