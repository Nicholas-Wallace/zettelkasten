# CONCEITO
There goes the *Extended Farkas’ Lemma* 

> $L2x \le l2 \to L1x \le l1$
> 	if, and only if
> 	there is a non negative matrix D, such that
> $DL2 = L1$
> $DL2 \le l1$

why this is useful? Its a powerful tool to test PI, and is very flexible so you can apply on n scenarios just abstracting that L2 needs to be a matrix and L1.
